Turtle Shape Designer - Version History

Version 1 - Rough first attempt
- Click points on a small grid and save Turtle code or a point list.
- Uses default-looking buttons and has only reset, colour, and export controls.
- Boundary issue 1: a shape with exactly 3 points is rejected, even though a triangle should be allowed.
- Boundary issue 2: trying to export before making a shape gives only a status message, with no clear warning.
- These issues are intentionally silent so they can be found during testing.

Version 2 - Better editing
- Fixes both Version 1 issues by allowing triangles and giving clearer export feedback.
- Adds snapping to nearby saved corners.
- Adds Undo last shape.
- Does not yet snap to lines or undo unfinished points.

Version 3 - More precise drawing
- Adds snapping to the nearest point on saved lines as well as corners.
- Adds Undo last point.
- Changes the controls and layout to look much more like the final version.
- Includes the snap-distance boundary so clicks exactly on the limit are handled.
- Shows a clear message when Undo last point is pressed with no unfinished points.

Version 4 - Current final version
- Turtle10 Final Version.py is the current version.
- Includes point and line snapping, undo point, undo shape, clear all, larger spacing, cleaner buttons, and built-in instructions.
- Shows the current unfinished point count while drawing.
- Keeps the completed boundary and undo fixes in the final release.
