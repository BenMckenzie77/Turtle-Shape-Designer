# Turtle Shape Designer

This project lets you create your own Turtle shapes by clicking points on a grid. Each shape can be made from different parts, such as a body, eyes, wheels, or other details.

You can choose the inside and outline colours, undo points or completed parts, clear the drawing, and save your work as either a Python Turtle program or a list of coordinates.

The project was improved through four versions. I started with a basic drawing tool, tested it, fixed boundary issues, added snapping to points and lines, and then improved the layout and controls.

## How to use it

1. Run the Final Version (Or any version of your choosing)
2. Click on the grid to place points.
3. Click **Add this shape part** when you have finished one part.
4. Keep adding parts to build the full shape.
5. Use the undo buttons if you make a mistake.
6. Use **Save Turtle program** to export the final shape.

Snap mode helps connect new points to nearby saved points or lines. It can be turned off if you want to place points freely.
