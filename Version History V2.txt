Turtle Shape Designer
Version History V2

Project purpose
This project lets someone build a compound Turtle shape by clicking points on a grid. The aim was to make the coordinate maths visible and let the user save the finished design as Python code.

Version 1 - First working attempt
What I built:
- A small Tkinter window with a canvas and basic controls.
- Mouse clicks became Turtle-style coordinates.
- Shape parts could be coloured and added to the drawing.
- The drawing could be exported as a Turtle program or a text point list.

What testing found:
- The validation used more than three points, so a triangle with exactly three points was rejected.
- Exporting before creating a shape only changed the status text, which was easy to miss.
- The controls were usable but looked like a first attempt and had very little editing support.

Version 2 - Fixing the first problems
Changes made:
- Changed the polygon check so three points are accepted.
- Added clearer feedback when there is nothing to export.
- Added corner snapping so a new part can connect neatly to an older corner.
- Added Undo last shape for removing the most recent finished part.

Reason for the changes:
The first tests showed that valid triangles should work and that users need a way to correct a finished part without resetting everything. Corner snapping was the first step toward more accurate joins.

Version 3 - Improving the interface and precision
Changes made:
- Added snapping to the nearest point on an existing line as well as corners.
- Added Undo last point for correcting the current unfinished part.
- Changed the layout, buttons, and spacing to move toward the planned final interface.

Testing issues left in this version:
- A click exactly on the snap-distance boundary was not included.
- Undo last point gave no useful response when there was no unfinished point.

These were left as testable issues for the final correction rather than hidden behind extra popups.

Version 4 - Final version
The current final file is Turtle10 Final Version.py.

Final improvements:
- Correct boundary handling for snapping and undo.
- Snapping works on both saved corners and saved lines.
- Separate Undo last point, Undo last shape, and Clear entire drawing actions.
- Larger canvas and window with more comfortable control spacing.
- Cleaner shared font and button styling.
- Instructions appear inside the same window at the bottom without moving the canvas.
- Comments explain the main decisions, coordinate conversion, drawing flow, editing actions, and exports.

Overall development path
Basic drawing -> testing exposed boundary issues -> corner snapping and undo -> line snapping and improved controls -> final fixes and clearer presentation.
